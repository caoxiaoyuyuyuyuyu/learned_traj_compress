\section{SVD Weight Geometry Details}
\label{app:svd_details}

\paragraph{Definitions.}
For a base weight matrix $\mathbf{W}_\text{base}\!\in\!\mathbb{R}^{m\times n}$ with truncated SVD $\mathbf{W}_\text{base}\!=\!\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^\top$, retain the top-$k$ singular vectors $\mathbf{U}_k$, $\mathbf{V}_k$. The observed alignment of a fine-tuning delta $\Delta\mathbf{W}\!=\!\mathbf{W}_\text{ft}-\mathbf{W}_\text{base}$ is
\[
\alpha_\text{obs}(k)=\frac{\|\mathbf{U}_k^\top\Delta\mathbf{W}\,\mathbf{V}_k\|_F}{\|\Delta\mathbf{W}\|_F},
\]
and the alignment ratio is $r(k)=\alpha_\text{obs}(k)/\alpha_\text{rand}(k)$ where $\alpha_\text{rand}(k)$ is the mean projection norm over $n\!=\!100$ Gaussian random matrices matched in shape and entry variance to $\Delta\mathbf{W}$. We decompose into U-side ($\|\mathbf{U}_k^\top\Delta\mathbf{W}\|_F/\|\Delta\mathbf{W}\|_F$) and V-side ($\|\Delta\mathbf{W}\,\mathbf{V}_k\|_F/\|\Delta\mathbf{W}\|_F$) components capturing concentration along base output vs.\ input directions.

\paragraph{Per-matrix dispersion.}
At $k\!=\!256$ the per-matrix distribution is right-skewed: $r_\text{RL}\!=\!2.78\!\pm\!2.57$, $r_\text{SFT}\!=\!1.47\!\pm\!2.19$ (mean $\pm$ std), with a few outlier layers reaching $r\!>\!10$. Only 2--3 layers show $r_\text{SFT}\!>\!r_\text{RL}$ (most notably layer~1 \texttt{mlp.down\_proj}); in those cases both ratios remain $r\!>\!2$, so the exceptions are high-alignment for both methods rather than SFT-dominant.

\paragraph{Layer-type decomposition.}
The alignment gap is not uniform. At $k\!=\!256$, MLP layers show stronger RL--base alignment ($3.49\!\times$) than attention layers ($2.25\!\times$), while SFT--base alignment is $2.01\!\times$ for MLP and only $1.07\!\times$ for attention---SFT attention deltas are nearly indistinguishable from random. The multi-objective capability encoded in attention weights is therefore the most resistant component to SFT transfer.

\paragraph{U-side / V-side asymmetry.}
For attention layers, U-side alignment dominates V-side ($0.31$ vs.\ $0.12$ at $k\!=\!256$): RL modifies how attention \emph{writes} its output more than how it reads. For MLP layers the pattern reverses (U-side $0.05$, V-side $0.11$): RL modifies how MLP layers select input features. A successful distillation method would need to replicate not just the magnitude but the directional structure of RL changes across these layer types.

\paragraph{Same-architecture comparison.}
Both the RL and SFT models compared here are full-rank fine-tunes of the same Qwen2.5-7B base, so alignment ratios reflect differences in training objective (PPO vs.\ behavior cloning) rather than dimensional or rank confounds. The distillation experiments in \S\ref{sec:distillation} use a separate Qwen2.5-3B / LoRA rank-32 student, reflecting the deployment cost constraint.

\section{Oracle Retrieval Injection: Implementation and Leakage Audit}
\label{app:oracle_impl}

\paragraph{Pseudocode.}
Algorithm~\ref{alg:oracle} describes our oracle retrieval injection. The implementation builds a map from each test prompt to the ordered list of \texttt{<information>} segments in the teacher's best (highest-EM) trajectory for that prompt (from \texttt{phase1d\_v2\_data/raw\_trajectories\_N*.json}). At inference time we run the student in an interactive loop, halting whenever it emits \texttt{</search>}, and inject the $j$-th teacher segment in response to the student's $j$-th search query. The mapping is \emph{positional} rather than query-similarity-based: we do not match on Jaccard or cosine similarity between the student query and the teacher query. This keeps the injection deterministic and reproducible, and it matches the teacher's own ordering of retrieval rounds.

\begin{algorithm}[h]
\caption{Oracle Retrieval Injection (exp\_009 / exp\_013).}
\label{alg:oracle}
\small
\begin{algorithmic}[1]
\State \textbf{Input:} Student prompt $p$, teacher trajectory $T_p$ (best-EM response), maximum search rounds $R$
\State \textbf{Output:} Student completion with oracle-injected retrieval segments
\State Parse $T_p$ into ordered information segments $[I_1,\ldots,I_k]$ using the regex \texttt{<information>.*?</information>}
\State $j \gets 0$; $\text{gen} \gets$ generate from $p$ with stop strings $\{\texttt{</search>},\texttt{</answer>}\}$
\While{$\text{gen}$ ends with \texttt{</search>} and $j < R$}
  \If{$j < k$}
    \State Append $I_{j+1}$ verbatim to $\text{gen}$
  \Else
    \State Append a no-hit \texttt{<information></information>} block
  \EndIf
  \State $j \gets j + 1$
  \State Continue generation from $\text{gen}$ until \texttt{</search>}, \texttt{</answer>}, or \texttt{max\_new\_tokens}
\EndWhile
\State \Return $\text{gen}$
\end{algorithmic}
\end{algorithm}

Concrete parameters: \texttt{max\_new\_tokens}${}=4096$, \texttt{max\_search\_rounds}${}=R=5$, greedy decoding (\texttt{do\_sample}${}=$\texttt{False}), model loaded as a merged LoRA adapter. Both Qwen-3B (exp\_009) and Llama-1B (exp\_013) use the same injection loop; only the base checkpoint and adapter change.

\subsection*{Leakage Audit}
\label{app:leakage_audit}

To verify that the oracle retrieval intervention does not trivially leak gold-answer strings, we run a substring audit on a random sample of 50 N=8 evaluation prompts (\texttt{scripts/oracle\_leakage\_audit.py}, seed=42). For each prompt, we concatenate all teacher-injected \texttt{<information>} blocks, lowercase and strip punctuation from both the concatenated text and the gold-answer strings (from the FlashRAG evaluation JSON), and record a hit if any gold answer is a substring of the concatenated blocks. As a control, we shuffle teacher passages across prompts (prompt $p$ receives passages from a random other prompt $p'$) and re-run the same check.

\small

\begin{tabular}{lr}
\toprule

\midrule

\bottomrule
\end{tabular}
\caption{Oracle retrieval leakage audit on 50 random N=8 test prompts.}
\label{tab:leakage_audit}

\paragraph{Interpretation.} The absolute 98\% real-hit rate is high, and the audit script's built-in decision threshold (${>}30\%$) tags this rate as ``non-trivial leakage''; we therefore retain the experiment as an \emph{upper-bound probe}, not as a clean causal estimate. Two independent checks nevertheless bound the leakage contribution: \textbf{(i)} the teacher MEM1 policy is trained with PPO on outcome rewards only, and its FlashRAG retriever receives no gold-label supervision at rollout time; \textbf{(ii)} under teacher-retrieval replay, student $\mathrm{em\_full}$ at $N=8$ remains $0.008$, far below the $\approx 1.0$ rate expected if passages directly exposed answers. Accordingly, the $+47.7$\,pp oracle em\_partial recovery should be read as a \emph{strict upper bound} on retrieval-side mitigation, not as a demonstration of perfect answer access. The 64\,pp real$-$shuffled gap itself quantifies retrieval topic specificity relative to the derangement baseline.

\paragraph{Limitations.} The substring match does not distinguish partial lexical overlap from semantic coverage; 50 samples is a sanity check rather than a full audit. A comprehensive audit covering all splits and semantic paraphrase matching is deferred to camera-ready.

\section{Activation Probing Details}
\label{app:probing}

We extract activation differences $\Delta\mathbf{h}_l = \mathbf{h}_l^\text{RL} - \mathbf{h}_l^\text{base}$ at layers $l \in \{0, 3, 7, 11, 15, 19\}$ for $n = 300$ prompts, projecting onto the top-$k$ principal directions ($k \in \{64, 256\}$) of the base model's weight matrices. Eight feature variants are tested: raw activations $\mathbf{h}^\text{RL}$, $\mathbf{h}^\text{base}$, their difference $\Delta\mathbf{h}$, and top-$k$ projections thereof.

\paragraph{Linear probes.} Binary classification (per-objective EM above/below median) achieves accuracy $0.72$, below the majority-class baseline $0.76$. Regression probes yield negative $R^2$ across all 55 (feature, layer, $k$) combinations.

\paragraph{MLP probes.} Two-layer MLPs (hidden dimension 128, ReLU) trained on the same features predict per-objective EM as a continuous target (Spearman $\rho$). MLP probes lose to linear probes in 47/55 cases (85.5\%; paired $t = -8.19$, $p = 4.83 \times 10^{-11}$, Cohen's $d = -1.105$). Mean $\rho$: $-0.011$ (MLP) vs.\ $0.073$ (linear).

\paragraph{Random-feature baseline.} We construct 5 random orthonormal bases $\times$ 6 layers $\times$ 2 $k$ values. The maximum $|\rho|$ under random features is $0.224$; 52/55 (94.5\%) of real linear probe $|\rho|$ values fall within this noise band. The per-objective signal in $\Delta\mathbf{h}$ is indistinguishable from random projections.

\section{Extended Related Work}
\label{app:extended_related}

\paragraph{Multi-objective RL for LLMs.}
Recent work explores multi-objective optimization in LLM alignment: Rewarded Soups~\cite{rame2024rewarded} interpolates weights fine-tuned on diverse rewards, MODPO~\cite{zhou2024modpo} extends DPO to multiple preference dimensions, and fine-grained human feedback~\cite{wu2024finegrained} decomposes rewards into per-aspect signals. These methods address \emph{training} with multiple objectives; our work addresses the complementary problem of \emph{distilling} multi-objective RL policies.

\paragraph{Preference learning and DPO.}
DPO~\cite{rafailov2023dpo} and extensions (IPO~\cite{gheshlaghi2024ipo}, KTO~\cite{ethayarajh2024kto}, RAFT++~\cite{dong2023raft}) provide offline alternatives to RLHF. We use DPO as a stronger-than-SFT baseline; its failure ($+1.0$pp, not significant) suggests behavioral mismatch rather than insufficient signal richness. Following~\citet{karl2024negative}, we frame this as a diagnostic contribution.

\section{Action-Sequence Accuracy: Per-Sample Forensics}
\label{app:asa_forensics}

A reviewer raised the concern that the near-identical action-sequence accuracy (ASA $=0.606$) for both Qwen-3B and Llama-1B at $N\!=\!8$ may reflect scoring-pipeline degeneracy rather than a genuine diagnostic signal. We investigate this with a per-sample forensic analysis.

\paragraph{Method.} We extract the per-sample ASA scores for both backbones (125 matched $N\!=\!8$ test prompts) by applying Eq.~\ref{eq:asa} to student--teacher action-tag sequence pairs. We then compute: (i)~per-sample exact match rate between the two backbone score vectors; (ii)~a $2\!\times\!2$ contingency table (binarised at $\text{ASA}\!\geq\!0.5$); (iii)~Cohen's $\kappa$.

\paragraph{Results.} The two per-sample score vectors are \textbf{identical}: 125/125 exact match (100\%), $\kappa\!=\!1.0$. The mechanism is simple: both students emit the same 3-token action prefix $\langle\texttt{think},\texttt{search},\texttt{information}\rangle$ on every sample (no variation across 125 prompts for either backbone). \paragraph{Verdict.} The ASA metric is \textbf{structurally degenerate} in the \texttt{honest\_search} setting: it collapses to $3/n_\text{teacher}$ for any student that has learned the initial action prefix, regardless of backbone identity or capacity. The near-identical 0.606 point estimates are therefore a metric artefact, not an independently informative diagnostic signal. This confirms the reviewer's concern. We retain ASA in the paper for completeness but no longer treat the cross-backbone coincidence as evidence of a shared ``silent-failure signature.'' All causal claims in the main text rest on the oracle-recovery contrast (\S\ref{sec:causal}) and em\_partial task metrics, not on ASA equality.

\label{app:redaction}

This appendix documents the passage-redaction protocol, pre-registered deviation log, fire-statistics, before/after samples, and bootstrap CI decomposition table for the \texttt{oracle\_redacted\_\{full,half\}} conditions introduced in \S\ref{sec:causal}.

\subsection{Protocol and Pre-Registered Deviation Log}
\label{app:redaction_protocol}

\paragraph{Pre-registered spec.}
On 2026-04-14, Director approved a 4-condition redaction plan (\texttt{honest\_search} / \texttt{oracle\_full} / \texttt{oracle\_redacted\_full} / \texttt{oracle\_redacted\_half}) on the phase1d\_v2 $N{=}8$ test split (125 prompts). The registered redaction spec was: ``substring-only redaction with \texttt{\_norm} normalisation, case-insensitive, replace each gold-answer substring with \texttt{[REDACTED]}''. Half-redaction was deterministic odd-indexed substring redaction (seed-free). Phase~1 sanity gate was a hard $\pm 0.02$ tolerance on \texttt{oracle\_full} em\_partial vs Table~\ref{tab:oracle_api} ($0.498$), with \texttt{blocker\_report}-on-violation (no self-diagnosis).

\paragraph{Executed spec.}
The worker (commits \texttt{7cf099d}, \texttt{fd1e172}) implemented substring matching with \textbf{word-boundary anchoring} (\verb|\b|) plus leading/trailing \textbf{quote-strip} on gold answers before regex compile. All other parameters unchanged: case-insensitive \texttt{\_norm}, \texttt{[REDACTED]} placeholder, deterministic uniform density halving for the \texttt{oracle\_redacted\_half} condition across all $125/125$ passages (see Deviation~3 below), 4 conditions, $\pm 0.02$ sanity gate, paired bootstrap 10k seed 42, positional oracle injection (\textit{j}-th block on \textit{j}-th \texttt{<search>}), greedy decoding at $\text{max\_new\_tokens}=4096$, base Qwen2.5-3B + LoRA \texttt{checkpoints/exp\_006\_sft\_shared}.

\paragraph{Rationale for deviation.}
Phase 0 dry-run found that pure substring redaction caused \textbf{pathological over-redaction} on short gold answers. Canonical example: a yes/no prompt with \texttt{gold\_answer="no"} caused every occurrence of ``November'', ``novelist'', ``now'', ``none'', ``nothing'' in the passage to be redacted to \texttt{[REDACTED]}, destroying surrounding context at noise level. Left unchanged, this would systematically collapse \texttt{oracle\_redacted\_full} toward the \texttt{honest\_search} floor regardless of mechanism, biasing the decision gate toward the \texttt{leakage\_dominated} branch and voiding the three-way pre-registered test. Word-boundary anchoring + quote-strip is the \emph{minimum-necessary semantic interpretation} of ``substring match'' that preserves the test's scientific validity while remaining faithful to the ``only redact the answer token, not surrounding context'' principle in the registered spec.

\paragraph{What is guaranteed unchanged.}
The 4 conditions, the $\pm 0.02$ Phase~1 hard-stop, the three-branch decision gate thresholds ($\geq +25$ / $+5..+25$ / $< +5$), paired bootstrap 10k resamples seed 42, the phase1d\_v2 $N{=}8$ 125-prompt split, positional oracle injection, the \texttt{[REDACTED]} placeholder, greedy/4096 generation, and model identity were all held fixed.

\paragraph{Non-deviations explicitly considered and rejected.}
Stemming, lemmatisation, stopword filtering, and paraphrase detection were all explicitly considered and rejected. Only word-boundary anchoring and quote-strip were added.

\paragraph{Deviation log summary.}
For the reviewer's convenience, the pre-registered deviation set is:
\begin{itemize}[leftmargin=*,nosep]
\item \textbf{Deviation 1 --- word-boundary anchoring + quote-strip} (substring match refinement): see ``Executed spec'' and ``Rationale for deviation'' paragraphs above. Minimum-necessary semantic interpretation of ``substring match'' to prevent pathological over-redaction on short gold answers (e.g., \texttt{"no"} matching ``November''/``novelist''), preserving the three-way pre-registered test's validity.
\item \textbf{Deviation 2 --- (reserved)}: no further substring-matching refinement beyond Deviation 1 was applied.
\item \textbf{Deviation 3 --- half condition uniform density halving (vs planned odd-indexed subset)}: the pre-registered plan.md specification called for a $50\%$ subset of passages to receive redaction (\emph{odd-indexed 62 of 125}). Both \texttt{oracle\_redacted\_full} and \texttt{oracle\_redacted\_half} apply redaction across all $125/125$ passages (not passage-level subsetting). The \texttt{half} condition reduces per-passage substitution count to $\sim 52\%$ of \texttt{full} ($867$ vs $1663$ substitutions via the preprocessing-level \texttt{redact\_info\_block\_tag} tool; the eval-details JSON count of $325$ vs $753$ reflects \texttt{generated\_text[:2000]} serialization truncation and is not the authoritative count). The half condition reduces per-substitution density uniformly across all 125 passages; the differential is implemented at substitution-sampling level (within \texttt{redact\_info\_block\_tag}), not at passage-level subsetting. The deviation preserves the plan's scientific intent (``roughly half the redaction dose, deterministic sub-selection'') and is a stricter dose-response control than a passage-level subset (which would leave $\sim 50\%$ of passages completely unredacted and conflate dose-response with passage-level variance). Verification via preprocessing-level authoritative count: \texttt{exp\_016\_workdir/residual\_leakage\_probe.json} (n\_redacted\_substitutions\_applied: 1663 full / 867 half, ratio $0.52$).
\end{itemize}

\subsection{Limitations of the Redaction Ablation}
\label{app:redaction_limitations}

Substring (word-boundary) redaction removes exact-match gold tokens but not paraphrase or partial-lexical hints (e.g. ``Einstein's theory'' surviving in a block after ``Albert Einstein'' is redacted). The reported $+11$\,pp retrieval-quality residual is therefore itself an \emph{upper bound} on the non-leakage mechanism; a tighter paraphrase-aware redaction would plausibly yield an even smaller retrieval-quality component. Conversely, the $+37$\,pp leakage component is a lower bound on the leakage-assisted mechanism for the same reason. The orthogonal checks from the v3.4 audit (teacher trained with PPO outcome-only rewards; $\mathrm{em\_full}=0.008$ at $N{=}8$ under oracle replay) remain as lower bounds on mechanism separation: the leakage contribution is substring-level answer-exposure enabling short-form decoding, not full-answer copy-paste.
