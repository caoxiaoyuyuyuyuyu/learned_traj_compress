\section{Conclusion}
\label{sec:conclusion}

Agentic SFT distillation can produce students that pass format-level, tool-call structural checks---perfect tool-call syntax and balanced XML tags, near-perfect query similarity (Jaccard $= 0.95$)---yet retain less than 6\% of the teacher's task performance. We have proposed a diagnostic protocol to detect this silent failure mode before pipeline deployment. The protocol proceeds by elimination: characterize the collapse shape, analyze weight geometry for geometric gaps between RL and SFT, and apply causal interventions (oracle and BM25 retrieval) that distinguish strategy acquisition from execution capability. Because the protocol requires only inference-time ablations, it is transferable to any agentic distillation setting where the teacher's competence depends on tool execution.

Applied to MEM1 (7B RL $\to$ 3B SFT), the protocol yields four findings: (1)~multi-objective performance degrades monotonically with no phase transition, setting slope reduction as the distillation target; (2)~RL weight changes concentrate $2$--$6\times$ supra-random along base principal directions, while SFT recovers only $1.47\times$---a geometric gap robust across 196 matrices ($p < 1.3 \times 10^{-32}$); (3)~DPO fails to close the gap ($+1.0$pp, power $> 0.99$ at 5pp), ruling out insufficient training signal; (4)~oracle retrieval recovers $+47.3$pp ($p < 0.0001$), causally confirming that behavioral mismatch accounts for ${\sim}86$--$88\%$ of the gap, with capacity contributing only ${\sim}12$--$14\%$. Even BM25 retrieval recovers $+6$--$12$pp, offering an immediately deployable mitigation.

\subsection{Limitations}
\label{sec:limitations}

\paragraph{Scope.}
All experiments use one RL teacher (MEM1, 7B) on one domain (multi-objective RAG QA). The literature survey (\S\ref{sec:related}) suggests the silent failure mode likely extends to other systems evaluated only by format-level, tool-call structural checks, but direct replication on other teachers and benchmarks remains future work.

\paragraph{Capacity isolation.}
A 7B full-rank pooled SFT quantifies the capacity contribution at $\approx$12--14\% of the teacher--student gap across all $N$ (\S\ref{sec:capacity}); however, the training-method mismatch (full-rank vs.\ LoRA) makes this a best-effort bound.

\paragraph{DPO data scarcity.}
DPO uses only 176 matched pairs ($0.4\%$ perfect rate at $N\!=\!8$), but power exceeds $0.99$ for a 5pp effect (floor 2.7pp). Oracle retrieval uses teacher passages (upper bound); BM25 retrieval confirms the finding generalizes beyond the oracle setting. Training a 3B RL baseline and cross-task generalization remain as future work.
