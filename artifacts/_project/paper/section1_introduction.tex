\section{Introduction}
\label{sec:intro}

SFT distillation of an RL-trained agent can appear to succeed by every standard metric---and still fail catastrophically in deployment. We distill MEM1~\cite{zhou2025mem1}, a Qwen2.5-7B retrieval-augmented QA agent trained with PPO via veRL~\cite{sheng2024verl}, into a Qwen2.5-3B student using 1{,}118 teacher trajectories. The student reproduces the teacher's \texttt{think}$\to$\texttt{search}$\to$\texttt{information}$\to$\texttt{answer} action structure with $>$95\% fidelity, generates search queries with Jaccard similarity $= 0.95$ to the teacher's, and matches the teacher's single-search pattern ($>$95\% of responses). By behavioral cloning metrics, distillation succeeded.

It did not. The student achieves $\text{em\_partial} = 0.025$ at $N\!=\!8$ simultaneous objectives---a 94.5\% drop from the teacher's $0.455$---with 83\% of outputs truncated by hallucinated search traces that consume the generation budget before producing answers. The failure is \emph{silent}: surface indicators---action structure fidelity ($>$95\%), query Jaccard similarity (0.95), single-search pattern match ($>$95\%)---all rate this student highly. The collapse surfaces only when search calls must return real results, i.e., at pipeline deployment. This is the central danger: an invisible failure that passes quality gates.

Why do richer training signals not help? DPO on matched preference pairs yields $+1.0$pp ($p = 0.163$)---preference learning fails because the problem is not what the student prefers to generate. Scaling from 3B to 7B SFT closes only ${\sim}12$--$14\%$ of the teacher--student gap (\S\ref{sec:capacity}), ruling out capacity as the primary bottleneck.

We introduce a diagnostic protocol that distinguishes \emph{strategy acquisition} from \emph{execution capability}. The key causal test: providing oracle retrieval at inference recovers em\_partial from $0.025$ to $0.498$ at $N\!=\!8$ ($+47.3$pp, $p < 0.0001$), with truncation dropping from 83\% to 0\%. Even a simple BM25 retrieval system recovers $+6$--$12$pp. The protocol proceeds by elimination---collapse characterization (\S\ref{sec:framework}), weight geometry analysis (\S\ref{sec:svd}), causal intervention (\S\ref{sec:distillation})---and localizes the failure before deployment (Figure~\ref{fig:framework}).

\paragraph{Contributions.}
\begin{itemize}[leftmargin=*,nosep]
    \item A \textbf{silent failure mode} in agentic SFT distillation: surface indicators (action structure fidelity, query similarity) give high scores while task performance retains $<$6\% of teacher capability.
    \item A \textbf{diagnostic protocol} (collapse characterization $\to$ weight geometry $\to$ causal intervention) that localizes the failure to execution-environment mismatch before pipeline deployment, applicable to any agentic distillation where the teacher's capability depends on tool execution.
    \item \textbf{Causal evidence and quantification}: oracle retrieval $+47.3$pp ($p < 0.0001$); capacity accounts for ${\sim}12$--$14\%$ of the gap; behavioral mismatch accounts for ${\sim}86$--$88\%$; DPO is an informative negative (power $> 0.99$ at 5pp).
    \item A \textbf{deployable mitigation}: BM25 retrieval recovers $+6$--$12$pp with no additional training, immediately deployable as a sidecar component.
\end{itemize}
