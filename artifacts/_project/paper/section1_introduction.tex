SFT distillation of an RL-trained agent can appear to succeed by format-level tool-call metrics---and still fail catastrophically in deployment. We distill MEM1~\cite{zhou2025mem1}, a Qwen2.5-7B retrieval-augmented QA agent trained with PPO via veRL~\cite{sheng2024verl}, into a Qwen2.5-3B student using 1{,}118 teacher trajectories. Format-level tool-call metrics give high scores---tool-call syntax ($100\%$), balanced XML tags ($100\%$), non-empty search queries ($100\%$), query Jaccard similarity ($0.95$)---all rate this student highly (Table~\ref{tab:silent_failure_demo}). Content-level similarity already warns (BLEU $1.14$ on sacrebleu's 0--100 scale, ROUGE-L $0.21$), but because the student produces teacher-like \emph{structure}, these content warnings are easy to dismiss as cosmetic noise. This specific blind spot---format compliance masking execution failure---mirrors the ``syntax-only'' tool-call evaluations critiqued by \citet{jhandi2025slm} (\S\ref{sec:related}).

It did not succeed. The student achieves $\text{em\_partial} = 0.025$ at $N\!=\!8$ simultaneous objectives---a 94.5\% drop from the teacher's $0.455$---with 83\% of outputs truncated by hallucinated search traces that consume the generation budget before producing answers. The failure is \emph{silent} at the format/syntax layer: the checks in Table~\ref{tab:silent_failure_demo} all pass while action-sequence accuracy at the token level is only $0.606$. The collapse surfaces only when search calls must return real results, i.e., at pipeline deployment. This is the central danger: an invisible failure that passes format-level tool-call quality gates while content-level warning signs are overridden by teacher-like structure.

Why do richer training signals not help? DPO on matched preference pairs yields $+1.0$pp ($p = 0.163$)---preference learning fails because the problem is not what the student prefers to generate. Scaling from 3B to 7B SFT closes only ${\sim}12$--$14\%$ of the teacher--student gap (\S\ref{sec:capacity}), ruling out capacity as the primary bottleneck.

We introduce a diagnostic protocol that distinguishes \emph{strategy acquisition} from \emph{execution capability}. The key causal test: providing oracle retrieval at inference recovers em\_partial from $0.025$ to $0.498$ at $N\!=\!8$ ($+47.3$pp, $p < 0.0001$), with truncation dropping from 83\% to 0\%. Even a simple BM25 retrieval system recovers $+6$--$12$pp. The protocol proceeds by elimination---collapse characterization (\S\ref{sec:framework}), weight geometry analysis (\S\ref{sec:svd}), causal intervention (\S\ref{sec:distillation})---and localizes the failure before deployment (Figure~\ref{fig:framework}).

\paragraph{Contributions.}
\begin{itemize}[leftmargin=*,nosep]
    \item A \textbf{silent failure mode} in agentic SFT distillation: format-level indicators (tool-call syntax, balanced XML tags, query similarity) give high scores while task performance retains $<$6\% of teacher capability.
    \item A \textbf{diagnostic protocol} (collapse characterization $\to$ weight geometry $\to$ causal intervention) that localizes the failure to execution-environment mismatch before pipeline deployment, applicable to any agentic distillation where the teacher's capability depends on tool execution.
    \item \textbf{Causal evidence and quantification}: oracle retrieval $+47.3$pp ($p < 0.0001$); capacity accounts for ${\sim}12$--$14\%$ of the gap; behavioral mismatch accounts for ${\sim}86$--$88\%$; DPO is an informative negative (power $> 0.99$ at 5pp).
    \item A \textbf{deployable mitigation}: BM25 retrieval recovers $+6$--$12$pp with no additional training, immediately deployable as a sidecar component.
\end{itemize}
